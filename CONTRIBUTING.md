# Contributing

Actualist is primarily a personal project. Bug reports and focused fixes are
welcome; discuss larger changes before starting them.

- Keep changes focused and check the affected behavior.
- Run `scripts/check.sh` and the relevant tests. See the
  [development guide](docs/DEVELOPMENT.md) for setup and commands.
- Keep credentials and personal budget data out of code, screenshots, and issues.
- Update documentation when a change affects how someone uses the app.

Contributions use the project's GPLv3 license with its
[App Store and TestFlight Exception](APP_STORE_EXCEPTION.md). Only submit work
you have the right to contribute. See [TRADEMARKS.md](TRADEMARKS.md) for branding.
