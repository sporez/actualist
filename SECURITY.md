# Security Policy

Actualist handles financial data and authentication material. Do not report a
suspected vulnerability, exposed credential, server address, budget identifier,
or unredacted diagnostic report in a public issue.

Use GitHub's **Report a vulnerability** flow in the repository Security tab to
send a private report. Include the affected version, impact, reproduction steps,
and the minimum redacted evidence needed to investigate.

For ordinary bugs that do not involve sensitive information or a security
boundary, use the public issue tracker.
