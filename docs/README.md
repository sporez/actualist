# Actualist Docs

This directory is split by how current the information is.

## Start Here

- `PLAN.md`: current product direction, architecture, data flow, and testing expectations.
- `DEVELOPMENT.md`: local build, test, TestFlight, Liquid Glass, and simulator workflow.
- `local-first-current-write-model.md`: current local-first write behavior, outbox model, supported writes, and limitations.
- `ROADMAP.md`: product roadmap for closing the gap with Actual Budget web/PWA while keeping Actualist native.

## Active Plans

Active implementation notes live in `plans/`:

- `plans/budget-templates.md`: remaining local-first budget template work.
- `plans/budget-keypad-followups.md`: deferred Budget keypad polish.

## Release Notes

- `testflight-releases.md`: manual and scripted TestFlight release workflow.

## Archive

Completed or superseded plans live in `old/`. Keep them for historical context
for now, but do not treat them as current implementation guidance unless a current
doc links to a specific archived detail.
